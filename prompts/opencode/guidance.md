# Skill library

You have a `manage_skill` tool in the `auto_learn` namespace from the auto-learn plugin. It saves skills to the user's OpenCode skill library at `{{skillsDir}}`. Find it with tool search when it is not already loaded. OpenCode offers saved skills whenever a task matches their descriptions.

When you work out a reusable setup sequence, debugging recipe or project workflow, save it: `create` a skill, `update` one you saved earlier, or `delete` one that turned out wrong.

- Keep exact commands, file locations and pitfalls, not conversation history or personal data.
- Check existing skills before creating one; update a skill you created instead of adding a near-duplicate.
- The tool changes only skills it created and refuses content that looks like a credential.
